SAFE MODE IMPLEMENTS TWO CONTROLS

What changes in safe mode?

  1. Parameterized query: the username is supplied through a ? placeholder, so SQL syntax in the input is treated as data.
  2. Password hashing: passwords are stored as salted scrypt hashes. The entered password is verified with scrypt and a timing-safe comparison; the original password is not used in the safe SQL query.

The plaintext password column exists only to make the vulnerable classroom exploit reproducible. Safe mode uses the salted hash fields. Never store plaintext passwords or deploy the vulnerable endpoint.
